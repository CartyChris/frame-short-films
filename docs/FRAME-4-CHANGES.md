# Frame 4.0 — motion production tools

- Motion workspace with Anime.js shape/text choreography, keyframes, easing, selectable objects, resizable panels, portrait/mobile layout and vector-only Lottie imports.
- Motion scenes participate in Chat plans, automatic Produce, manual AI revision, exact-prefix recovery, project backup, split/trim, HTML and MP4. Imported vector data stays outside model prompts and is restored by stable reference. AI revisions keep the visible source range of trimmed clips.
- Editable motion-source export/reopen preserves the source document, clip duration and source offset.
- Optional cinematic finish in 3D: bloom, vignette, exposure, brightness/contrast, hue/saturation and presets; same shared engine for editor, portable film and rendered video. Existing ungraded scenes retain the legacy path.
- Production tools: editable segment/word captions, beat/onset analysis and reviewed cut suggestions, LosslessCut cut-list import that appends source-referencing clips, and paired local ComfyUI workflow submission/status/media retrieval.
- ComfyUI preserves requested/remote identities and unknown outcomes. Status checks never automatically re-submit. Workflow review, bounded loopback transport and existing companion authentication remain in place.
- Optional Python helpers for real librosa analysis and WhisperX transcription/alignment checkpoints. No GPU engines, model checkpoints or hidden installers are bundled.
- Tool library documents all 20 reviewed projects, canonical repositories and their current role. New runtime libraries are pinned, with notices embedded in portable exports.

Prior Frame3 projects and releases remain compatible. The original PulseForge app/source is unchanged. Source ZIP supplies Mac packaging, Vercel deployment and GitHub workflows; local workstations remain necessary for external desktop/Python tools.
