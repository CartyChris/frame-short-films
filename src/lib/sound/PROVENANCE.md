# PulseForge source provenance

Frame Sound Studio adapts the user's PulseForge Studio source, copied on 2026-11-06 from the user-provided PulseForge Studio source. The original application was not modified or launched. Selected pure producer and musical-time modules were executed in isolation for bounded parity checks. `source-hashes.json` records SHA-256 of each original module copied.

Included: original procedural DSP, kits, synthesis presets/engines, mixer effects, musical time, note/pattern/project schema, seeded composition/director, composition-to-session mapping, event compilation, and WAV encoding. Adaptations remove the sampled-instrument registry and its downloads, add Frame bounds/validation, and use a separate bounded offline render wrapper and Frame persistence. Original UI/state/backend/secret storage were not copied. A small drum-role type is extracted from the original kit vocabulary.

The original `BUNDLED_AUDIO_LICENSES.md` calls its procedural sound expansions original work under MIT. The source package has no standalone root LICENSE or package license field. This copy is authorized reuse of user-provided source; this notice records provenance without asserting third-party licensing rights. Preserve this notice with source redistribution.

No Salamander / VSCO recordings or other third-party sample assets are included. Instruments labelled piano, strings, brass, choir and guitar are synthesized approximations. Tone.js and Zod have their own dependency licenses; installed distributions include them. Frame exports synthesized audio as WAV rather than redistributing a sample library.

Adapted files preserve their original relative paths under `pulseforge/`. The bounded adapter and UI are new Frame code. Specific source corrections: Zod 4 prefaults preserve nested default parsing; procedural-only instrument registry; subtractive modulation connects to a real filter; piano cutoff has a valid lower bound; asynchronous instrument/effect impulse responses finish before render; rack solo removes other compiled events; mixer solo retains output routes; effect-construction failures are reported rather than silently dropping the requested effect. The new renderer disposes audio graphs, serializes offline context access, validates source bounds, checks finite/non-silent PCM, and optionally folds loop tails. The original archive/asset persistence, network tools, local-secret handling, live engine, and renderer are not reused.

Verification on 2026-11-06 re-read the 14 original source modules listed in `source-hashes.json`; all SHA-256 values still matched the intake. This checks those inspected modules, not a claim that every file in the unrelated original app was audited. The original app was not run. The original and adapted pure producer/time modules matched exactly across 30 fixtures under the same Zod 4.6.7 dependency; an isolated timing defect was rejected in 25 fixtures. This is not whole-app or audio-render parity. Focused sound tests and real-browser checks are documented in `README.md`.
